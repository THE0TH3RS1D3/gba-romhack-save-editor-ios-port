# Gen 3 Save Editor for iPhone

iPhone port of the *GBA Romhack Save Editor* (Ruby/Sapphire/Emerald/FireRed/LeafGreen and ROM hacks such as
Unbound, Radical Red, Emerald Legacy, Imperium, Heart & Soul). Names of Pokémon, items and moves are read from
the ROM you open.

## Build the IPA on GitHub (no Mac needed)
1. Create a new GitHub repository and upload **everything in this folder** (including the hidden `.github` folder).
2. Open the repo's **Actions** tab → *Build iOS IPA* → **Run workflow** (it also runs on every push).
3. When it is green, open the run and download the artifact **GBASaveEditor-ipa** (a zip containing `GBASaveEditor.ipa`).
   Pushing a tag like `v1.0` also attaches the IPA to a GitHub release.

The IPA is **unsigned**. Install it with a tool that signs for you: AltStore / SideStore, Sideloadly,
or TrollStore (needs a compatible iOS version). With a free Apple ID the app must be re-signed every 7 days.

## Use
1. **File** tab → *Open ROM* (the `.gba`; first scan takes a few seconds, then it is cached) → *Open save* (`.sav`/`.srm`).
2. **Pokémon**: party list and PC boxes (grid or list). Tap a slot to edit; tap an empty slot to create a Pokémon.
   The editor has species / nickname / item / level+exp (linked) / nature / ability / shiny / happiness / ball,
   moves, IVs, EVs, calculated stats, Hidden Power, and slot actions (move/swap, copy, delete).
3. **Bag**: pocket chips, searchable item picker (only items belonging to the pocket), quantities, add/remove rows, *Apply pocket*.
4. **Trainer**: name and money. **Info**: what was detected in ROM and save.
5. **Save** (top right) → share sheet → *Save to Files* and replace your save. *Export original (backup)* on the File tab
   saves the untouched original under a `.bak` name. iOS apps cannot write next to the file they opened, hence the export step.

Settings (File tab): sprite preview (read from the ROM), larger editor sprite, remember last ROM/save.

## Differences from the desktop version
* The PKHeX-style drag-and-drop interface is replaced by touch actions inside the editor (move/swap/copy/delete).
* The `.bak` is exported on request instead of being written automatically.
* Everything else (all save layouts, ROM scanning, caching, checksum handling) follows the desktop code.

## Technical notes
`App/www/gen3lib.js` is a line-by-line port of `gen3lib.py`; the UI is plain HTML/JS shown in a `WKWebView`
(`App/Sources/GBASaveEditorApp.swift`), project generated by XcodeGen (`project.yml`). `node tests/test_engine.js` runs a
self-contained round-trip test.
